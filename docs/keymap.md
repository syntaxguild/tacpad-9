# Profile keymaps

Generated from the compiled `include/keymap.h`. Run `python scripts/check_firmware.py --write-keymap` after changing bindings.

Tap the encoder in Macro mode to cycle profiles. Hold 1.5 seconds for XO. Physical legends match Coding; the OLED shows the selected profile and action.

## CODING

| Key | OLED label | Shortcut / consumer action |
|---:|---|---|
| 1 | COPY | CTRL+C |
| 2 | PASTE | CTRL+V |
| 3 | BUILD | CTRL+SHIFT+B |
| 4 | BLENDER | CTRL+ALT+SHIFT+B |
| 5 | UNDO | CTRL+Z |
| 6 | REDO | CTRL+Y |
| 7 | PLAY | MEDIA PLAY |
