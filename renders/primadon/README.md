# Tacpad 9 / Primadon

The final project name is **Tacpad 9**, also called **Model Nine**.
The supplied pixel mascot is the **Primadon** team logo.

| Photograph | Size |
| --- | --- |
| Tacpad_9_Primadon_1x1.png | 2048 x 2048 |
| Tacpad_9_Primadon_16x9.png | 2560 x 1440 |

Open `Tacpad_9_Primadon.blend` in Blender 4.0 or newer. The active scene is
`Tacpad 9 / Primadon Studio`; cameras `01 / SQUARE / 1 to 1` and
`02 / WIDESCREEN / 16 to 9` contain the two compositions. Press F12 to render.
Logo, fonts, lighting and materials are packed into the project.

See `../../docs/tacpad9-design.md` for sources, rebuilding and export details.
The exports folder contains STL and OBJ/MTL assemblies with millimetre coordinates.
